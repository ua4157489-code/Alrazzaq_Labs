# Data Structures

## Tuple

An ordered and immutable collection.

Example

```python
coordinates = (10, 20, 30)
```

---

## Set

An unordered collection of unique values.

Example

```python
numbers = {1,2,3}
```

# Tuple Characteristics

- Ordered
- Immutable
- Allows duplicates
- Faster than lists
- Uses ()

---

# Set Characteristics

- Unordered
- Mutable
- Unique values only
- Fast membership testing
- Uses {}

---

# Tuple vs Set

| Tuple | Set |
|--------|-----|
| Ordered | Unordered |
| Immutable | Mutable |
| Allows duplicates | No duplicates |
| Indexing supported | No indexing |
