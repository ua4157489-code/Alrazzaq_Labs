# 🔄 Tuple vs Set

| Tuple | Set |
|--------|-----|
| Ordered | Unordered |
| Immutable | Mutable |
| Allows duplicates | Unique values only |
| Uses () | Uses {} |
| Faster for fixed data | Faster membership testing |
