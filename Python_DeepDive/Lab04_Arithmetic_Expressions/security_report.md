# Security Report — Lab 04: Arithmetic & Expressions

## Security Objective

Develop secure Python programming practices while performing mathematical operations and handling user input safely.

---

## Security Considerations

- Validate all user input before calculations.
- Prevent division by zero.
- Handle invalid numeric input using exception handling.
- Avoid exposing unnecessary application errors.

---

## Best Practices

- Verify input data types.
- Use meaningful variable names.
- Implement input validation.
- Handle runtime exceptions gracefully.
- Follow Python coding standards (PEP 8).

---

## Skills Demonstrated

- User Input Handling
- Arithmetic Operations
- Expression Evaluation
- Integer Division
- Float Division
- Basic Error Prevention

---

## Result

The lab successfully demonstrated Python arithmetic operations, mathematical expressions, and different division techniques. Safe handling of user input and prevention of common runtime errors reinforce reliable programming practices for future Python development.
