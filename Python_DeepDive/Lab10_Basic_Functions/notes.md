# Lab Notes – Basic Functions

## Overview

Functions are reusable blocks of code designed to perform a specific task.

They help organize programs into smaller, manageable components.

---

## Function Syntax

```python
def function_name(parameters):
    return value
```

---

## Parameters

Parameters receive data passed into a function.

Example:

```python
def greet(name):
```

---

## Arguments

Arguments are the actual values passed during a function call.

```python
greet("Alice")
```

---

## Return Statement

Returns a value back to the caller.

```python
return "Hello"
```

---

## Default Parameters

Provide a default value if no argument is supplied.

```python
def greet(name="Guest"):
```

---

## Keyword Arguments

Arguments can be passed by parameter name.

```python
greet(name="Alice")
```

---

## Benefits of Functions

- Code reuse
- Easier debugging
- Better readability
- Modular programming
- Reduced duplication

---

## Real-World Uses

- Security scripts
- Cloud automation
- APIs
- DevOps
- System administration
- Data analysis

---

## Outcome

Successfully created reusable Python functions using parameters, default values, and keyword arguments.
