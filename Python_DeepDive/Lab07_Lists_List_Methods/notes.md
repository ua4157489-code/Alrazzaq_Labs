# Common List Methods

| Method | Purpose |
|---------|----------|
| append() | Add an item |
| remove() | Remove an item |
| sort() | Sort items |
| pop() | Remove by index |
| insert() | Insert at position |
| clear() | Remove all items |
| reverse() | Reverse order |
| count() | Count occurrences |
| index() | Find item index |

# Common Mistakes

- Removing non-existent elements.
- Index out of range.
- Forgetting lists are mutable.
- Confusing append() with insert().

---

# Best Practices

- Check data before removing.
- Use descriptive variable names.
- Keep lists organized.
