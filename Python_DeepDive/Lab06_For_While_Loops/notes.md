# Loop Types

## For Loop

Used when the number of iterations is known.

Example

```python
for i in range(5):
    print(i)
```

---

## While Loop

Runs while a condition remains True.

Example

```python
while x < 5:
    x += 1
```

# For vs While

| For | While |
|------|--------|
| Fixed iterations | Unknown iterations |
| Uses iterables | Uses conditions |
| Cleaner syntax | Flexible |
