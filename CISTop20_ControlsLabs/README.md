# 📖 About

This repository documents my practical implementation of the **CIS Critical Security Controls** through hands-on laboratory exercises.

The primary goal of this repository is to build practical cybersecurity knowledge by implementing security controls in real-world lab environments. Each lab is carefully documented with commands, configuration files, verification steps, troubleshooting, and learning outcomes.
