# Security Report

## Lab

Understanding Conditionals

---

## Security Overview

Although this lab focuses on conditional logic rather than cybersecurity, secure coding principles are still important.

---

## Security Considerations

- Validate all user input.
- Prevent invalid data types.
- Handle unexpected values.
- Avoid unnecessary code execution.

---

## Risks

- Invalid numeric input.
- Program crashes due to incorrect data.
- Lack of exception handling.

---

## Recommendations

- Use try/except blocks.
- Validate user input.
- Display meaningful error messages.
- Follow secure coding standards.

---

## Best Practices

- Keep conditions simple.
- Avoid nested logic where possible.
- Test edge cases.
- Follow PEP 8 coding standards.

---

## Risk Level

**High**

---

## Status

**No security vulnerabilities identified in the lab implementation.**
