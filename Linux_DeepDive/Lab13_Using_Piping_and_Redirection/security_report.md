# Security Report

## Objective

Demonstrate secure handling of Linux command output using redirection and piping.

---

## Activities Performed

- Redirected command output to files.
- Appended additional data without overwriting.
- Filtered process information using pipes.
- Verified redirected output.
- Combined multiple commands for efficient data processing.

---

## Security Considerations

- Avoid overwriting important files with `>`.
- Verify redirected output before sharing.
- Be cautious when redirecting sensitive information.
- Limit exposure of process information.
- Use pipes to safely filter command output.

---

## Skills Demonstrated

- Linux CLI
- Bash
- Input/Output Redirection
- Pipes
- Command Chaining

---

## Result

Successfully demonstrated Linux piping and redirection techniques while following safe command-line practices for handling command output.
