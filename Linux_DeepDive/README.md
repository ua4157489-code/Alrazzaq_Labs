## 📖 About This Repository

This repo documents my complete hands-on journey through the **Linux Deep Dive** lab series — a 60-part practical curriculum covering everything from your very first `cd` command to configuring **LVM**, **SELinux**, and **firewall rules**. Every lab below has been **completed** on the [Alnafi LMS](https://apps.lms.alnafi.com/), and each entry links straight back to the original unit.

> 💡 **Why this matters:** Linux isn't just an OS — it's the backbone of servers, cloud infrastructure, containers, and DevOps pipelines. These labs build real muscle memory for the command line, one skill at a time.
