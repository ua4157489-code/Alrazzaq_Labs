# Security Report

## Objective

Practice secure Linux ownership management.

---

## Activities Performed

- Created sample files.
- Verified ownership.
- Changed file owner.
- Changed group ownership.
- Applied recursive ownership.
- Verified changes.

---

## Security Considerations

- Applied Principle of Least Privilege.
- Assigned ownership only to authorized users.
- Used groups for secure collaboration.
- Verified ownership after every modification.
- Avoided unnecessary privileged ownership.
