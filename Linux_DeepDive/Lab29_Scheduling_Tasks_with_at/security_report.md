# Security Report

## Purpose

This lab focused on securely automating one-time Linux administrative tasks using the **at** scheduling utility.

## Security Practices

- Verified installation before use.
- Ensured the atd daemon was running correctly.
- Scheduled only trusted commands.
- Removed unnecessary pending jobs.
- Used administrative privileges only when required.

## Security Impact

Proper management of the **at** utility helps:

- Automate administrative tasks securely.
- Reduce manual intervention.
- Improve operational efficiency.
- Prevent forgotten maintenance activities.
- Support secure Linux system administration.

## Result

One-time task scheduling, monitoring, and removal were successfully completed using the native Linux **at** scheduling service.
