# Security Report

## Objective

Understand Linux file permissions and access control.

---

## Activities Performed

- Created a sample file.
- Inspected file permissions.
- Modified permissions using symbolic mode.
- Modified permissions using numeric mode.
- Verified changes.

---

## Security Considerations

- Applied the principle of least privilege.
- Avoided insecure permission settings such as `777`.
- Verified permissions after each modification.
- Ensured controlled file access.

---

## Skills Demonstrated

- Linux Access Control
- File Permission Management
- Command-Line Administration
- Security Best Practices

---

## Result

Successfully managed Linux file permissions while following security best practices for protecting files and controlling user access.
