# Security Report

## Lab Objective

Practice secure directory management using Linux command-line tools.

---

## Activities Performed

- Created directories
- Renamed directories
- Moved directories
- Removed empty directories
- Removed directories recursively

---

## Security Considerations

- Verified directory contents before deletion.
- Used `rmdir` for empty directories whenever possible.
- Used `rm -r` cautiously to avoid accidental data loss.
- Maintained an organized directory structure.

---

## Skills Demonstrated

- Linux Directory Management
- Filesystem Navigation
- Safe File Operations
- Command-Line Administration

---

## Result

Directory operations were completed successfully while following safe filesystem management practices.
