# Security Report

## Objective

Practice creating and managing Linux hard and symbolic links.

---

## Activities Performed

- Created original file.
- Created hard link.
- Created symbolic link.
- Compared inode numbers.
- Compared metadata.
- Tested link functionality.
- Verified behavior after file deletion.

---

## Security Considerations

- Avoid symbolic links pointing to sensitive files.
- Remove broken symbolic links.
- Verify inode information before modifying files.
- Use links carefully in shared environments.

---

## Skills Demonstrated

- Linux File Systems
- Link Management
- Inode Analysis
- Linux Administration
- File Security

---

## Result

Successfully demonstrated Linux hard and symbolic links while understanding their structure, behavior, and security considerations.
