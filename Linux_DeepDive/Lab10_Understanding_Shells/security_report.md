# Security Report

## Objective

Understand Linux shell environments and secure shell usage.

---

## Activities Performed

- Identified the default shell.
- Listed installed shells.
- Verified the active shell.
- Switched between available shells.
- Returned to the original shell.

---

## Security Considerations

- Verified the active shell before executing commands.
- Used trusted shell executables.
- Avoided changing the default shell without authorization.
- Confirmed shell availability using `/etc/shells`.

---

## Skills Demonstrated

- Linux Shell Management
- Command-Line Navigation
- Shell Identification
- Linux Administration
- Environment Verification

---

## Result

Successfully explored Linux shell environments, identified available shells, switched between sessions, and verified shell configuration following Linux administration best practices.
