# Security Report

## Purpose

This lab focused on strengthening Linux user authentication by implementing secure password policies and password aging configurations.

## Security Practices

- Reviewed existing password aging policies.
- Configured password expiration periods.
- Configured password expiry warning notifications.
- Reviewed system-wide password policy settings.
- Examined PAM password complexity configuration.

## Security Impact

Proper password policies help:

- Reduce unauthorized access.
- Enforce regular password changes.
- Improve authentication security.
- Support compliance with security standards.
- Strengthen Linux account protection.

## Result

Password policy configuration and verification were completed successfully using native Linux security tools and configuration files.
