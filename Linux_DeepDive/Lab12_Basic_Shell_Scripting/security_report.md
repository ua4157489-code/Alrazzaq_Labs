# Security Report

## Objective

Demonstrate secure creation and execution of a basic Bash shell script.

---

## Activities Performed

- Created a Bash script.
- Added a shebang to specify the interpreter.
- Granted execute permissions using `chmod`.
- Executed the script directly and via Bash.
- Verified script permissions and output.

---

## Security Considerations

- Only make trusted scripts executable.
- Review script contents before execution.
- Avoid running unknown scripts with elevated privileges.
- Restrict execute permissions to authorized users when appropriate.
- Store scripts in secure locations with proper access controls.

---

## Skills Demonstrated

- Bash Scripting
- Linux CLI
- Script Execution
- File Permission Management
- Basic Automation

---

## Result

Successfully created, executed, and verified a basic Bash shell script while following safe scripting and permission management practices.
