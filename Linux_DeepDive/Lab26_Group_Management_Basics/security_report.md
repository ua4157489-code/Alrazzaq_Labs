# Security Report

## Purpose

This lab focused on securely managing Linux user groups to improve permission management and access control.

## Security Practices

- Created groups using administrative privileges.
- Assigned users to appropriate supplementary groups.
- Verified memberships after every modification.
- Removed unnecessary group memberships.
- Followed the principle of least privilege.

## Security Impact

Proper group management:

- Improves access control.
- Reduces administrative overhead.
- Prevents unauthorized access.
- Supports secure multi-user environments.

## Result

Group creation, membership modification, verification, and removal were completed successfully using standard Linux administration tools.
