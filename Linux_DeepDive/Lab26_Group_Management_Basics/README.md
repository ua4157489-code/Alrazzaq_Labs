# 👥 Lab 26: Group Management Basics

> **This lab demonstrates practical Linux system administration techniques for creating, managing, and auditing user groups. It focuses on Linux access control, permission management, and secure administration using native command-line utilities.**

---

# 📖 Overview

Linux groups provide an efficient way to manage permissions for multiple users. Instead of assigning permissions individually, administrators assign users to groups, making access control simpler and more secure.

This lab demonstrates the complete workflow of creating groups, adding and removing users from groups, and verifying memberships using standard Linux administration commands.

---

# 🎯 Objectives

- Understand Linux group management
- Create new groups
- Add users to groups
- Remove users from groups
- Verify group memberships
- Learn group administration best practices

---

# 📚 Commands Covered

| Command | Purpose |
|----------|----------|
| `groupadd` | Create a new group |
| `grep` | Verify group creation |
| `usermod -aG` | Add user to supplementary group |
| `groups` | Display group membership |
| `gpasswd -d` | Remove user from group |
