# Security Report

## Objective

Demonstrate safe Linux process monitoring and management using standard administration tools.

---

## Activities Performed

- Enumerated running processes.
- Monitored CPU and memory utilization.
- Identified process IDs.
- Practiced terminating processes using PID.
- Practiced terminating processes using process names.
- Reviewed Linux process signals.

---

## Security Considerations

- Verify process identity before termination.
- Prefer `kill` (SIGTERM) before `kill -9` (SIGKILL).
- Avoid terminating essential system services.
- Monitor abnormal resource consumption.
- Use least privilege when managing system processes.

---

## Skills Demonstrated

- Linux Process Management
- Process Enumeration
- Resource Monitoring
- Signal Handling
- System Administration

---

## Result
Successfully demonstrated Linux process monitoring, resource analysis, and secure process management using standard Linux administration commands.
