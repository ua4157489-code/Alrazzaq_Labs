# Security Report

## Objective

Demonstrate the use of Linux networking tools to inspect interfaces, verify connectivity, and troubleshoot DNS resolution securely.

---

## Activities Performed

- Examined network interface configuration.
- Displayed IP addressing information.
- Tested network connectivity using ICMP.
- Queried DNS records using `nslookup` and `dig`.
- Reviewed routing and DNS configuration.
- Inspected active network connections.

---

## Security Considerations

- Do not expose internal IP addresses publicly.
- Verify trusted DNS servers before troubleshooting.
- Limit unnecessary open network ports.
- Monitor active network connections regularly.
- Use modern networking tools (`ip` and `ss`) where possible.

---

## Skills Demonstrated

- Linux Networking
- Network Diagnostics
- DNS Troubleshooting
- Connectivity Testing
- System Administration

---

## Result

Successfully demonstrated Linux networking fundamentals by inspecting interfaces, validating connectivity, resolving DNS records, and reviewing network configuration using standard Linux administration tools.# Security Report
